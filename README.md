# AI Guide Content

직원들의 AI 온보딩을 돕기 위한 가이드 페이지 원천 콘텐츠를 관리한다.
실제 사이트나 페이지 구현물은 별도 위치에서 제작한다.

## GitHub Pages

GitHub Pages는 저장소 루트의 `index.html`을 진입점으로 사용한다.
현재 `index.html`은 `AI하이커-안내서.html`로 이동한다.

## Structure

| Folder | Purpose |
|---|---|
| `content/design-guide/` | 에쓰푸드 디자인 시스템과 브랜드 적용 가이드 |
| `content/global-instructions/` | Claude, Codex, Gemini 등 AI 도구별 전역 지침 |
| `content/security-guide/` | 보안, 개인정보, 민감정보 처리 가이드 |
| `content/skills/` | AI 업무 스킬, 프롬프트 패턴, 역할별 활용법 |
| `content/usage/` | 설치, 실행, 기본 사용법, 자주 쓰는 워크플로우 |

## Rule

콘텐츠 원천은 `content/`에 작성한다.
시각 스타일은 `content/design-guide/sfood-design-system.md`를 따른다.
