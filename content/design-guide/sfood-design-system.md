## 1. 브랜드 컨셉

### Core Values — 3축

| 축 | 컬러 기반 | 표현 방식 |
|---|---|---|
| **Vitality (활력)** | S-Red (#D5413E) | 단백질·육류의 풍부한 에너지, 건강한 힘 |
| **Warmth (온기)** | Cream Gold (#FCF0D6) | 자연 재료의 따뜻함, 장인 정신, 식탁의 온기 |
| **Trust (신뢰)** | BG Dark (#2B2B2B) | 정돈된 구조, 품질과 안전에 대한 약속 |

### 로고 참조 규칙

사용자가 "우리 회사 로고를 넣어줘"라고 요청하면 아래 4종 로고를 우선 참조한다. 작업 매체의 배경색과 사용 크기에 따라 적합한 파일을 선택하며, 별도 요청이 없으면 일반 배경에는 Normal, 어두운 배경에는 Darkmode 파일을 사용한다.

| 용도 | 로컬 참조 위치 | 권장 사용 |
|---|---|---|
| 기본 로고 | `content/design-guide/assets/brand/SFOOD_CI_Normal.png` | 흰색·밝은 배경, 표지/문서 상단 등 큰 크기 |
| 기본 소형 로고 | `content/design-guide/assets/brand/SFOOD_CI_Normal_Small.png` | 흰색·밝은 배경, 머리글/푸터/작은 배치 |
| 다크모드 로고 | `content/design-guide/assets/brand/SFOOD_CI-Darkmode_Normal.png` | 어두운 배경, 표지/섹션 타이틀 등 큰 크기 |
| 다크모드 소형 로고 | `content/design-guide/assets/brand/SFOOD_CI_Darkmode_Small.png` | 어두운 배경, 작은 배치 |

- 원본 보관용 파일: `content/design-guide/assets/brand/SFOOD_CI.pdf`
- 향후 웹 연동 시 각 로고는 `web_url` 값을 추가해 관리한다. 예: Google Drive, Dropbox, 사내 CDN 등에서 공유 가능한 원본 링크를 등록한다.
- 웹 참조가 등록된 경우에도 로컬 파일명을 기준 식별자로 유지하고, 로컬 파일이 없을 때만 `web_url`에서 내려받아 사용한다.
- 외부 공유 링크는 권한 만료와 파일 교체 가능성이 있으므로, 최종 산출물 제작 전 링크 접근 가능 여부를 확인한다.

## 4. Border Radius 시스템

> 모든 박스·카드에는 반드시 Radius를 적용합니다. 직각(0) 박스 사용 금지.

| 토큰 | 값 | 적용 대상 |
|---|---|---|
| `--r-xs` | 4px | 아이콘 버튼, 마이크로 배지 |
| `--r-sm` | 6px | 태그, 칩, 인라인 배지, 소형 코드 블록 |
| `--r-md` | 10px | **입력 필드, 버튼, 소형 카드** (일반 컴포넌트 기본값) |
| `--r-lg` | 14px | **일반 카드, 패널, 팝업** (카드 기본값) |
| `--r-xl` | 20px | 대형 카드, 모달, 섹션 배너 |
| `--r-2xl` | 28px | 히어로 섹션, 대형 컨테이너 |
| `--r-pill` | 9999px | 필 버튼, 아바타, 상태 인디케이터 |

**선택 기준:** 박스의 최소 너비·높이의 약 15–20%를 Radius 값으로 설정하는 것이 적절한 비율입니다.  
예: 높이 40px 버튼 → r-md(10px), 높이 200px 카드 → r-lg(14px)~r-xl(20px)

### 문서 작성 양식

#### Word 문서
- 사용자가 별도 색상을 지정하지 않는 이상, 본문·제목·표 텍스트는 검은색 단색으로 통일한다.
- 머리글 영역을 활용해 작성 부서와 작성일을 우측 정렬로 표기한다. 폰트 크기는 9pt를 기본으로 하고, 색상은 연한 그레이(#9E9388)를 사용한다.
- 머리글의 작성일은 `yyyy.mm.dd` 형식으로 표기한다.
- 바닥글 영역에는 자동 페이지 번호를 적용하고, 머리글과 같은 9pt와 연한 그레이(#9E9388)로 `- 번호 -` 형식으로 표기한다.
- 작업 시작 전, 문서 방향을 세로형으로 할지 가로형으로 할지 사용자에게 먼저 확인한다.
- 표를 배치할 때는 현재 문단 폭과 문서 레이아웃에 맞춰 표의 가로 폭을 조정한다.
- 표의 셀 안쪽 여백은 좁게 설정한다.
- 표 헤더는 항상 연한 그레이 배경을 적용하고, 헤더 제목은 중앙 정렬한다.
- 표에 숫자가 들어갈 경우 3자리마다 쉼표(,)를 적용하고, 별도 요청이 없으면 우측 정렬한다.

#### PowerPoint 장표
- 사용자가 별도 배경을 지정하지 않는 이상, 장표 배경은 흰색을 기본값으로 한다.
- 첫 장은 항상 커버 페이지로 구성한다.
- 커버 페이지는 중앙 센터 정렬 타이틀 영역을 기본으로 한다.
- 커버 페이지 좌측 하단에는 작성일을 표기하고, 우측 하단에는 에쓰푸드 로고를 배치한다.
- 커버 페이지 하단 중앙에는 `Better Food, Better World`를 센터 정렬로 배치하고, S-Red(#D5413E)로 표시한다.
- 전체 장표의 상하좌우 여백은 좁게 설정해 사용 가능 영역을 넓게 확보한다.
- 타이틀은 검은색을 기본값으로 하며, 모든 장표에서 세로 높이를 줄인 고정 타이틀 영역을 사용한다.
- 타이틀 영역 아래에는 연한 그레이 구분선을 넣어 본문 영역과 명확히 구분한다.
- 본문 페이지는 상단에 텍스트 영역을 두고, 기본 본문 텍스트는 현재보다 한 단계 작은 크기로 사용한다.
- 상단 텍스트 아래에는 요약 영역을 두며, 요약 텍스트는 타이틀보다 작게 하고 볼드 처리한다. 요약은 2줄을 기본으로 하며 길어도 3줄을 넘기지 않는다.
- 요약 영역 아래에는 구분선을 넣고, 그 아래를 본문 영역으로 사용한다.
- 각주를 삽입할 때는 본문 하단 구분선 아래에 번호 형식으로 표시한다.
- 첫 장과 마지막 장에는 페이지 번호를 표기하지 않는다.
- 마지막 장은 항상 `Thank You`를 크게 중앙 센터 정렬로 배치하고, 맨 아래에는 에쓰푸드 로고를 작게 배치한다.
- 페이지 번호는 우측 정렬 레이아웃을 기본으로 하며, 우측 하단에 작게 배치하고 다른 구성요소에 가려지지 않게 한다.
- 페이지 번호 위에는 연한 그레이 구분선을 넣어 본문 영역과 분리한다.
- 두 번째 장은 항상 INDEX 페이지로 구성하고, 전체 목차를 넣는다. INDEX 페이지에는 카드형 디자인을 적용하지 않는다.
- 작업 시작 전, 슬라이드 비율을 4:3 또는 16:9 중 무엇으로 만들지 사용자에게 먼저 확인한다.
- 표를 사용할 때는 테두리를 얇게 적용한다(0.25pt 또는 0.5pt). 테두리 색상은 배경 대비에 맞춰 #666 또는 #999 중 선택한다.
- 그래프는 기본적으로 데이터 레이블이 보이는 형태로 삽입하고, 범례는 하단 배치를 기본으로 한다.

## 8. 주의사항 (Do & Don't)

### ✅ Do
- 컬러는 팔레트 토큰만 사용한다
- **모든 박스·카드에 반드시 Radius를 적용한다**
- 박스 크기에 비례해 Radius 토큰을 선택한다
- 크림(#FCF0D6)은 보색 배경·강조 영역에 적극 활용한다
- 다크 배경(#2B2B2B)에서는 White 또는 Gold Light 텍스트만 사용한다
- 레드(#D73135)는 호버/강조 변형에만, 기본값은 #D5413E를 사용한다

### ❌ Don't
- 팔레트 외 임의 색상 추가 금지
- 카드·박스에 Radius 0 (직각) 사용 금지
- 작은 요소에 과도한 Radius 적용 금지 (버튼에 r-2xl 등)
- 텍스트-배경 대비 4.5:1 미만 조합 금지
- Semantic 컬러(Success/Warning/Error) 장식 목적 사용 금지
- 세리프(Serif) 폰트 공식 문서 사용 금지
- 동일 페이지에 3가지 이상 폰트 혼용 금지
