# Skills

직원들이 반복 업무에 사용할 AI 스킬과 프롬프트 패턴을 정리한다.

## Initial Categories

| Category | Purpose |
|---|---|
| 문서 작성 | 보고서, 기획서, 메일, 회의록 작성 |
| 데이터 분석 | 표 정리, 요약, 지표 해석, 이상치 점검 |
| 시스템 기획 | 요구사항 정리, 화면 기획, 업무 프로세스 구조화 |
| 보안 점검 | 민감정보 탐지, 공개 가능성 검토 |
| 디자인 적용 | SFOOD 디자인 시스템 기반 웹·문서 스타일 적용 |

## Rule

각 스킬은 목적, 입력 예시, 출력 형식, 주의사항을 함께 작성한다.
